Fit once. Transform the holdout.

The web adapter calls the existing DataPulseEngine.fit_transform on the training split. It then calls transform on the holdout with the fitted schema, imputation, outlier, scaling, encoding and selection parameters.

The synthetic generator can deliberately shift holdout income and marketing channels. Uploaded CSVs use a seeded random split, stratified for classification. That random split is not a chronological production-monitoring exercise.

Training encoding has its own contract.

High-cardinality categoricals use out-of-fold target encoding during fitting. Applying the final artifact to training rows would use the full fitted mapping instead. Use the exported training CSV to train a downstream model.

The website does not fit or evaluate a prediction model. Finite numeric output is a preprocessing check, not evidence of improved predictive performance.

Resampling stays on training data.

SMOTE or Borderline SMOTE runs only on the training matrix. The engine may skip it for already balanced data, small classes, regression or sampler constraints; the result reports whether it ran and why it was skipped.

The holdout is transformed without resampling. The downloaded inference artifact excludes the training-only resampler.

Take the work with you.

The export contains processed training and holdout CSVs (with target), a fitted .joblib pipeline and metadata, configuration, and a run report. Load it using the DataPulse source package and compatible versions listed in its metadata.

The web demo is bounded to 1,200 input rows. It reuses the original modeling library, while the browser provides the interactive tables and diagnostics. Explore the implementation ↗
